# Ручна матриця перевірки

Синтетичні тести доводять математику розпізнавання, але не те, що справжня
Dota виглядає як наші макети. Ці п'ять прогонів — єдине справжнє свідчення.

Перед релізом пройти всі рядки. Кожен знімок з прогону зберегти в
`tests/corpus/` з іменем `<ширина>x<висота>_<мова>_<елемент>.png`.

| # | Конфігурація | Кроки | Очікування | Пройдено / Дата |
|---|---|---|---|---|
| 1 | 1080p без рамки, RU | `--calibrate`, пройти майстер, дочекатися матчу | усі три елементи знайдено, матч прийнято, `accept.png` з'явився з `source: opportunistic` | |
| 2 | той самий клієнт EN | змінити мову в Steam, `--calibrate` | майстер працює з чужим текстом, автопідказка або ручна рамка | |
| 3 | 1280×720 у вікні | змінити роздільну здатність, **не** калібрувати | калібрування перераховано автоматично, кнопки знаходяться | |
| 4 | масштаб UI на максимум | посунути повзунок у налаштуваннях Dota | або підлаштувалось, або прийшло повідомлення про калібрування | |
| 5 | Dota на другому моніторі | перетягнути вікно | вікно знайдено, кнопки знаходяться, `--diagnose` показує правильний прямокутник | |

## Звідки беруться знімки

**Меню, активний пошук, вікно на другому моніторі.** Це видно на екрані скільки
завгодно довго, тому знімок робить діагностика — запустіть її тоді, коли потрібне
на екрані:

```bash
python main.py --diagnose
```

Архів ляже у `diagnostics/`, всередині — `screenshot.png` з вікном Dota і
`report.json` з тим, які елементи знайдено просто зараз.

**Вікно прийняття — окремий випадок.** Попап живе кілька секунд, і бот натискає
кнопку майже одразу: зняти його вручну неможливо, а `--diagnose` запускається
окремо і не встигне. Тому кадр зберігає сам бот у ту саму мить, коли ловить попап:

```
diagnostics/corpus/<ширина>x<висота>_accept.png
```

Один файл на розмір вікна — корпусу потрібні різні конфігурації, а не сотні
знімків тієї самої. Нічого натискати не треба, просто дочекайтеся матчу.

## Що класти в корпус

`tests/test_corpus.py` читає з `tests/corpus/` файли за маскою `*_accept.png` —
саме ті, що бот зберіг сам. Перед копіюванням додайте до імені мову клієнта:
`1920x1080_ru_accept.png`.

**Репозиторій публічний.** На кадрі видно нік у Steam, а іноді список друзів, і
потрапить він у git назавжди. Обріжте знімок до вікна прийняття — детектору цього
достатньо, а зайвого в історії не лишиться.
